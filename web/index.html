How it works

  1. Importa un audio y asigna el ID de la canción de Geometry Dash.
  2. Selecciona la versión y pulsa EXPORT FOR GEODE.
  3. Se descargará como song-ID.ext.
  4. Copia ese archivo a la carpeta de datos de GD Free NONGs del mod Geode.
  5. Abre el Jukebox y actualiza My NONGs. El mod lo detectará automáticamente.

Los datos de esta biblioteca permanecen en el almacenamiento de este navegador. Exporta copias de seguridad si vas a borrar los datos del navegador o cambiar de dispositivo.
