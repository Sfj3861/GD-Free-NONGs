WELCOME TO GD FREE NONGs

What is this?

Una biblioteca comunitaria para descubrir y publicar versiones alternativas de canciones asociadas a Geometry Dash.

  1. Busca una canción por nombre o ID.
  2. Abre su ficha y elige una versión.
  3. Pulsa SAVE para guardar la preferencia en este perfil web.
  4. Para aplicarla dentro del juego, abre el Jukebox del mod y selecciona allí la versión.

El emparejamiento entre el navegador y el mod todavía no está implementado. Guardar una preferencia aquí no cambia automáticamente la canción del juego.
